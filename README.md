# RoboMaster 视觉入门工程 (C++ / OpenCV)

本项目是备战 RoboMaster 视觉组的大一学习工程，旨在从零搭建一个标准化的 C++ 计算机视觉流水线。项目涵盖了从环境配置、基础图像处理、视频流实时处理到形态学优化的完整闭环。

## 🛠️ 核心功能

1. **图像预处理**：BGR 转 HSV 色彩空间，进行颜色阈值过滤（`cv::inRange`）。
2. **目标提取**：寻找色块轮廓（`cv::findContours`）并计算外接矩形（`cv::boundingRect`）。
3. **逻辑过滤**：根据目标面积（`cv::contourArea`）和长宽比（Aspect Ratio）剔除环境噪点。
4. **后处理去重**：手写 NMS 算法（基于 IoU 交并比），剔除重叠的候选框。
5. **视频流处理**：使用 `cv::VideoCapture` 实时读取，控制窗口缩放并实现无限循环播放。
6. **形态学降噪**：利用开闭运算（`cv::morphologyEx`）填补目标空洞、消除反光噪点。

## 📅 开发日志 (Changelog)

### Day 1-3：工程环境搭建与传统视觉基础
- **环境搭建**：配置 WSL2 (Ubuntu 24.04) + VS Code + CMake + OpenCV 4.6。
- **图像处理**：掌握 `imread`、`cvtColor`（转HSV）、`inRange`（颜色掩膜）。
- **过滤逻辑**：通过 `contourArea` 实现面积过滤，通过 `boundingRect` 计算长宽比过滤。
- **算法集成**：将手搓的 **NMS（非极大值抑制）** 算法以多文件形式集成进工程，成功剔除重叠框。
- **Git进阶**：掌握了创建分支，解决 Merge 冲突，并成功在 GitHub 提交了 PR (Pull Request)。

### Day 4：视频流处理、性能监测与性能瓶颈分析
- **视频流**：使用 `VideoCapture` 替换 `imread`，通过 `while(true)` 循环实现逐帧读取处理。
- **性能监控**：使用 `getTickCount` 和 `getTickFrequency` 计算 `Read`（读图）耗时与 `Process`（处理）耗时，并实时打印在画面上。
- **核心提速**：发现高清视频处理卡顿后，使用 `cv::resize` 将画面降采样（缩小一半），FPS 从低于 100 飙升至 200 以上。
- **循环播放**：通过 `cap.set(cv::CAP_PROP_POS_FRAMES, 0);` 实现视频读取到末尾后自动倒带重播。

### Day 5：颜色切换与形态学降噪实战
- **场景挑战**：将阈值切为提取“白色”。受视频中的反光与白墙干扰，瞬间产生 **1676 个** 轮廓，导致 CPU 负担极重。
- **形态学魔法**：引入 `cv::getStructuringElement` 构建 5x5 核，利用 `morphologyEx` 的 `MORPH_OPEN`（开运算）进行降噪。
- **数据验证**：经过形态学过滤后，原始轮廓数量从 1676 暴降至 **81**，成功保住了 CPU 算力。

### Day 6：复杂场景调优与极限性能榨干
- **场景挑战**：挑战星空动态视频，提取红色流星。由于流星头部极亮、尾部偏暗，导致原本被切分成两个框。
- **调优策略**：
  1. 放宽 `ratio` 上限，适应极长的尾迹。
  2. 使用大尺寸核（如 `15x15` 或 `21x21`）进行 `MORPH_CLOSE`（闭运算），强行将碎裂的头部和尾部连通。
- **惊人战果**：成功用**单一绿框**完整锁定流星头尾。由于轮廓数量大幅减少，算法耗时维持在 **1ms**，FPS 突破 **400**，实现了极致的性能榨干。
