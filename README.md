# RM 视觉组入门工程 (Day 3)

这是一个基于 C++ 和 OpenCV 的视觉目标检测过滤工程。

## 功能实现
1. **颜色提取**：使用 HSV 色彩空间提取指定颜色（如红色/蓝色）。
2. **形态学与轮廓**：寻找色块轮廓并计算外接矩形。
3. **长宽比过滤**：过滤不符合装甲板物理比例（1.5 - 4.0）的噪点。
4. **NMS 去重**：手写非极大值抑制算法，剔除重叠的候选框。

## 环境依赖
* C++ 11 及以上
* OpenCV 4.x
* CMake

## 编译与运行
```bash
mkdir build && cd build
cmake ..
make
